🌿 사이트 개요

ECO Guest house의 결제 없는 예약 사이트입니다. 손님은 객실을 보고 예약을 신청하고, 주인은 관리자 페이지에서 객실·사진·예약을 관리합니다.

  • 손님 사이트: / (메인 주소)
  • 관리자 페이지: /admin
  • 3개국어: 몽골어 / 한국어 / 영어 (우측 상단에서 전환)
  • 예약 시 결제는 받지 않으며, 신청이 들어오면 주인이 확인 후 연락합니다.

🧳 손님(사용자) 사용법

1. 예약하기

  1. 메인 화면에서 객실을 둘러보고, 원하는 방의 "이 객실 예약" 버튼을 누릅니다.
  2. 예약 폼에서 객실을 선택합니다.
  3. 달력에서 체크인 → 체크아웃 날짜를 클릭합니다.
    • 회색·취소선 날짜는 이미 예약됨이라 선택할 수 없습니다.
    • 지난 날짜도 선택할 수 없습니다.
  4. 이름·연락처·이메일(필수)·인원·(선택)방문 국가·요청사항을 입력합니다.
  5. "예약 요청 보내기" → "접수되었습니다" 팝업이 뜨고, 입력한 이메일로 확인 메일이 발송됩니다.
이메일은 예약자가 사이트에서 확인 메일을 받아야 하므로 필수 입력입니다.

2. 내 예약 조회

상단 메뉴 "예약 조회 / My booking" → 예약 시 입력한 이메일을 넣으면, 본인 예약 목록과 상태를 볼 수 있습니다.

3. 언어 전환

우측 상단 MN / KO / EN 버튼으로 언어를 바꿉니다. 한 번 고르면 그 브라우저에서는 계속 그 언어로 보입니다.

🔑 관리자 로그인

  1. /admin 주소로 접속합니다.
  2. 비밀번호를 입력하고 로그인합니다. (비밀번호는 주인만 알고 있어야 합니다.)
  3. 상단 탭: 객실 관리 · 사이트 사진 · 예약 관리 · 설정
관리자 화면도 우측 상단 MN/KO/EN으로 언어를 바꿀 수 있습니다. (이건 관리자 본인이 보는 언어입니다.)

🛏️ 객실 관리

객실 관리 탭에서 방을 추가·수정·삭제합니다.

객실 추가 / 편집

  1. "+ 객실 추가" 또는 기존 방의 "편집"을 누릅니다.
  2. 언어 탭(🇲🇳/🇰🇷/🇬🇧)마다 이름·설명을 입력합니다. (한 언어만 넣어도 됩니다.)
  3. 가격(₮/박), 최대 인원, 사이트 공개 여부를 설정합니다.
  4. 저장을 누르면 저장되고 창이 닫힙니다.

사진 추가

  1. 새 방은 먼저 저장한 뒤, 목록에서 그 방의 "편집"을 다시 엽니다.
  2. "📷 사진 추가"로 여러 장 업로드합니다.
  3. 사진을 클릭하면 대표사진으로 지정되고, ✕로 삭제합니다.
공개를 끄면 손님 사이트에 그 방이 안 보입니다(예: 수리 중인 방).

🖼️ 사이트 사진

사이트 사진 탭에서 메인 화면의 슬라이드 사진을 관리합니다.

  • 메인 배경(히어로) 슬라이드 — 첫 화면 배경에서 넘어가는 사진들
  • 소개 섹션 슬라이드 — "소개" 부분에 표시되는 사진들

각 항목에서 "📷 사진 추가"로 여러 장 올리면 자동으로 넘어갑니다. ✕로 삭제합니다. 사진이 없으면 기본 배경만 보입니다.

📋 예약 관리

예약 관리 탭에서 들어온 예약을 확인하고 상태를 바꿉니다. 새 예약이 있으면 탭에 빨간 숫자가 표시됩니다.

예약 상태

  • 대기 손님이 막 신청한 상태 (아직 미확정)
  • 확정 예약을 받아들임 → 손님에게 확정 메일 발송
  • 불가 받을 수 없음(거절) → 손님에게 안내 메일, 날짜 다시 풀림
  • 취소 확정 후 취소 → 손님에게 취소 메일, 날짜 다시 풀림

처리 방법

  1. 각 예약 줄의 ✔ 확정 / ⊘ 불가 / ✖ 취소 버튼으로 상태를 바꿉니다.
  2. 상태를 바꾸면 손님과 주인 모두에게 자동 이메일이 나갑니다.
  3. 🗑 버튼으로 예약을 완전히 삭제할 수 있습니다.
  4. 상단 필터(전체/대기/확정/불가/취소)로 골라볼 수 있습니다.
불가·취소된 예약의 날짜는 다시 예약 가능해집니다. 대기·확정만 날짜를 잡아둡니다. 같은 방·겹치는 날짜는 자동으로 중복 예약이 차단됩니다.

⚙️ 설정 — 기본 언어

설정 탭에서 손님 사이트 기본 언어를 정합니다.

  • 처음 방문한 손님(언어를 아직 안 고른 사람)에게 이 언어로 보여줍니다. (기본값: 영어)
  • 🇲🇳 / 🇰🇷 / 🇬🇧 중 클릭하면 즉시 저장됩니다.
  • 손님이 직접 언어를 바꾸면 그 손님에게는 그 선택이 우선됩니다.

🔒 비밀번호 변경

  1. 관리자 우측 상단 "비밀번호" 버튼을 누릅니다.
  2. 현재 비밀번호 → 새 비밀번호(4자 이상) → 확인을 입력하고 저장합니다.
  3. 변경 후 다른 기기의 로그인은 자동으로 풀립니다(현재 창은 유지).
비밀번호는 안전한 곳에 보관하세요. 잊어버리면 서버 설정(환경변수 ADMIN_PASSWORD)으로만 초기화할 수 있습니다.

🛠️ 문제 해결 / 자주 묻는 질문

Q. 메일이 안 와요

  1. 관리자 "메일 테스트" 버튼을 눌러 결과를 확인합니다.
  2. 성공인데 안 보이면 스팸함을 확인하세요.
  3. 실패 메시지가 뜨면 이메일 설정(발송 계정/비밀번호)을 점검해야 합니다.

Q. 예약·사진·설정이 사라져요

서버의 영구 저장소(볼륨)가 연결돼 있어야 재배포 후에도 데이터가 유지됩니다. 데이터가 초기화된다면 운영자(개발자)에게 볼륨 설정을 확인 요청하세요.

Q. 손님이 "오류가 발생했습니다"를 봐요

대개 화면을 오래 열어둔 뒤 생긴 일시적 문제입니다. 페이지 새로고침(Ctrl+F5) 후 다시 시도하면 됩니다.

Q. 기본 언어가 영어인데 왜 나는 한국어로 보이나요?

이전에 그 브라우저에서 한국어를 골랐기 때문입니다. 손님의 선택이 기본값보다 우선합니다. 기본값 확인은 시크릿 창으로 하세요.

Q. 연락처·주소를 바꾸려면?

사이트 하단 "오시는 길" 영역의 정보 수정은 운영자(개발자)에게 요청하세요.

문의는 사이트 운영자에게 연락하세요.
