🌿 Overview

This is the no-payment booking site for ECO Guest house. Guests browse rooms and request a booking; the owner manages rooms, photos and bookings from the admin page.

  • Guest site: /
  • Admin page: /admin
  • 3 languages: Mongolian / Korean / English (top-right switch)
  • No payment is taken — after a request comes in, the owner confirms and contacts the guest.

🧳 For guests

1. Making a booking

  1. Browse rooms and click "Book this room".
  2. Select the room in the form.
  3. On the calendar, click check-in then check-out.
    • Grey / struck-through dates are already booked.
    • Past dates can't be chosen.
  4. Enter name, phone, email (required), guests, optional country and requests.
  5. "Send booking request" → a confirmation email is sent to that address.
Email is required because the guest receives a confirmation email.

2. Look up my booking

Top menu "My booking" → enter the email you used to see your bookings and their status.

3. Language

Use MN / KO / EN at the top-right. Your choice is remembered on that browser.

🔑 Admin login

  1. Go to /admin.
  2. Enter the password and log in.
  3. Tabs: Rooms · Site photos · Bookings · Settings
The admin screen also has MN/KO/EN (this is the language you see).

🛏️ Managing rooms

Add / edit a room

  1. Click "+ Add room" or "Edit" on a room.
  2. Per language tab (🇲🇳/🇰🇷/🇬🇧) enter name & description (one language is enough).
  3. Set price (₮/night), max guests, and visibility.
  4. Save — it saves and closes.

Photos

  1. For a new room, save first, then reopen it with "Edit".
  2. Use "Add photo" to upload several. Click a photo to set the cover; ✕ deletes it.
Turning visibility off hides the room from the guest site.

🖼️ Site photos

The Site photos tab controls the home-page slideshows.

  • Hero slideshow — background photos on the first screen
  • About slideshow — photos in the "About" section

Use "Add photo" to upload several; they auto-rotate. ✕ deletes. No photos = plain background.

📋 Managing bookings

The Bookings tab shows incoming requests. A red number on the tab means new requests.

Statuses

  • Pending just requested, not decided
  • Confirmed accepted → guest gets a confirmation email
  • Rejected can't accept → guest is notified, dates freed
  • Cancelled cancelled after confirming → guest notified, dates freed

How to handle

  1. Use ✔ Confirm / ⊘ Reject / ✖ Cancel on each row.
  2. Changing status emails both guest and owner automatically.
  3. 🗑 deletes the booking. Filter by status at the top.
Rejected / Cancelled free the dates again; only Pending / Confirmed hold them. Overlapping dates on the same room are blocked automatically.

⚙️ Settings — default language

The Settings tab sets the default site language for first-time visitors (default: English). Click 🇲🇳/🇰🇷/🇬🇧 to save instantly. A guest's own choice still wins.

🔒 Password

  1. Open the "···" menu → Password.
  2. Current → new (4+ chars) → confirm, then save.
  3. Other devices are logged out; your current window stays.
Keep the password safe. If lost, it can only be reset via the server variable ADMIN_PASSWORD.

🛠️ Troubleshooting / FAQ

Email doesn't arrive

  1. Use Email test and read the result.
  2. If it says success, check the spam folder.
  3. If it fails, the sending account/password needs checking.

Data disappears (bookings/photos/settings)

The server's persistent volume must be attached so data survives redeploys. If data resets, ask your operator to check the volume.

A guest sees "Something went wrong"

Usually a stale page. Refresh (Ctrl+F5) and try again.

Default is English but I see Korean

That browser previously chose Korean; a visitor's choice wins. Test the default in a private window.

🌿 사이트 개요

ECO Guest house의 결제 없는 예약 사이트입니다. 손님은 객실을 보고 예약을 신청하고, 주인은 관리자에서 객실·사진·예약을 관리합니다.

  • 손님 사이트: /
  • 관리자: /admin
  • 3개국어: 몽골어 / 한국어 / 영어 (우측 상단 전환)
  • 결제는 받지 않으며, 신청이 들어오면 주인이 확인 후 연락합니다.

🧳 손님 사용법

1. 예약하기

  1. 객실을 보고 "이 객실 예약"을 누릅니다.
  2. 예약 폼에서 객실을 선택합니다.
  3. 달력에서 체크인 → 체크아웃을 클릭합니다.
    • 회색·취소선 날짜는 이미 예약됨입니다.
    • 지난 날짜는 선택할 수 없습니다.
  4. 이름·연락처·이메일(필수)·인원·(선택)국가·요청을 입력합니다.
  5. "예약 요청 보내기" → 입력한 이메일로 확인 메일이 발송됩니다.
예약자가 확인 메일을 받아야 하므로 이메일은 필수입니다.

2. 내 예약 조회

상단 메뉴 "예약 조회" → 예약 시 입력한 이메일로 예약과 상태를 확인합니다.

3. 언어 전환

우측 상단 MN / KO / EN. 한 번 고르면 그 브라우저에서 유지됩니다.

🔑 관리자 로그인

  1. /admin 접속
  2. 비밀번호 입력 후 로그인
  3. 탭: 객실 관리 · 사이트 사진 · 예약 관리 · 설정
관리자 화면도 MN/KO/EN으로 바꿀 수 있습니다 (관리자 본인이 보는 언어).

🛏️ 객실 관리

객실 추가 / 편집

  1. "+ 객실 추가" 또는 "편집"을 누릅니다.
  2. 언어 탭(🇲🇳/🇰🇷/🇬🇧)마다 이름·설명을 입력합니다(한 언어만 넣어도 됨).
  3. 가격(₮/박)·최대 인원·공개 여부를 설정합니다.
  4. 저장하면 저장되고 창이 닫힙니다.

사진 추가

  1. 새 방은 먼저 저장한 뒤 "편집"을 다시 엽니다.
  2. "📷 사진 추가"로 여러 장 업로드. 사진 클릭 시 대표사진, ✕로 삭제.
공개를 끄면 손님 사이트에 그 방이 안 보입니다.

🖼️ 사이트 사진

사이트 사진 탭에서 메인 슬라이드를 관리합니다.

  • 메인 배경(히어로) 슬라이드 — 첫 화면 배경
  • 소개 섹션 슬라이드 — "소개" 부분

"📷 사진 추가"로 여러 장 올리면 자동으로 넘어갑니다. ✕로 삭제. 사진이 없으면 기본 배경만 보입니다.

📋 예약 관리

예약 관리 탭에서 예약을 확인·처리합니다. 새 예약이 있으면 탭에 빨간 숫자가 뜹니다.

예약 상태

  • 대기 막 신청됨(미확정)
  • 확정 받아들임 → 손님에게 확정 메일
  • 불가 받을 수 없음 → 손님 안내, 날짜 풀림
  • 취소 확정 후 취소 → 손님 안내, 날짜 풀림

처리 방법

  1. 각 줄의 ✔ 확정 / ⊘ 불가 / ✖ 취소 버튼 사용.
  2. 상태를 바꾸면 손님·주인 모두에게 자동 이메일이 발송됩니다.
  3. 🗑로 삭제. 상단 필터로 상태별 조회.
불가·취소는 날짜를 다시 풀고, 대기·확정만 날짜를 잡습니다. 같은 방 겹치는 날짜는 자동 차단됩니다.

⚙️ 설정 — 기본 언어

설정 탭에서 손님 사이트 기본 언어를 정합니다(기본값: 영어). 🇲🇳/🇰🇷/🇬🇧 클릭 시 즉시 저장. 손님이 직접 고른 언어가 우선됩니다.

🔒 비밀번호

  1. 우측 "···" 메뉴 → 비밀번호.
  2. 현재 → 새 비번(4자 이상) → 확인 후 저장.
  3. 다른 기기 로그인은 풀리고, 현재 창은 유지됩니다.
비밀번호는 안전하게 보관하세요. 분실 시 서버 변수 ADMIN_PASSWORD로만 초기화됩니다.

🛠️ 문제 해결 / FAQ

메일이 안 와요

  1. 메일 테스트 결과를 확인.
  2. 성공인데 안 보이면 스팸함 확인.
  3. 실패면 발송 계정/비밀번호 점검.

예약·사진·설정이 사라져요

서버 영구 저장소(볼륨)가 연결돼야 재배포 후에도 유지됩니다. 초기화되면 운영자에게 볼륨 확인을 요청하세요.

손님이 "오류가 발생했습니다"를 봐요

그 브라우저에서 전에 한국어를 골랐기 때문입니다. 기본값은 시크릿 창으로 확인하세요.

🌿 Тойм

Энэ бол ECO Guest house-ийн төлбөргүй захиалгын сайт. Зочид өрөө үзээд захиалга илгээнэ; эзэн нь админ хэсгээс өрөө, зураг, захиалгыг удирдана.

  • Зочны сайт: /
  • Админ: /admin
  • 3 хэл: Монгол / Солонгос / Англи (баруун дээд талд)
  • Төлбөр авахгүй — захиалга ирсний дараа эзэн баталгаажуулж холбогдоно.

🧳 Зочдод зориулсан

1. Захиалга хийх

  1. Өрөөнүүдийг үзээд "Энэ өрөөг захиалах" дарна.
  2. Маягтаас өрөө сонгоно.
  3. Хуанли-с ирэх → гарах өдрийг дарна.
    • Саарал/зураастай өдрүүд аль хэдийн захиалагдсан.
    • Өнгөрсөн өдрийг сонгох боломжгүй.
  4. Нэр, утас, имэйл (заавал), зочдын тоо, (сонголт) улс, хүсэлт бөглөнө.
  5. "Захиалга илгээх" → тухайн имэйл рүү баталгаажуулах захидал очно.
Зочин баталгаажуулах имэйл хүлээн авах тул имэйл заавал шаардлагатай.

2. Миний захиалга

Дээд цэс "Захиалга шалгах" → захиалахдаа оруулсан имэйлээр захиалга ба төлвийг харна.

3. Хэл солих

Баруун дээд MN / KO / EN. Нэг сонгоход тухайн хөтөч дээр хадгалагдана.

🔑 Админ нэвтрэх

  1. /admin руу орно.
  2. Нууц үг оруулж нэвтэрнэ.
  3. Таб: Өрөө · Зураг · Захиалга · Тохиргоо
Админ дэлгэц дээр мөн MN/KO/EN байдаг (энэ нь таны харах хэл).

🛏️ Өрөө удирдах

Өрөө нэмэх / засах

  1. "+ Өрөө нэмэх" эсвэл "Засах" дарна.
  2. Хэлний таб бүрт (🇲🇳/🇰🇷/🇬🇧) нэр, тайлбар оруулна (нэг хэл ч болно).
  3. Үнэ(₮/шөнө), дээд тоо, харагдах эсэх-ийг тохируулна.
  4. Хадгалах — хадгалаад цонх хаагдана.

Зураг нэмэх

  1. Шинэ өрөөг эхэлж хадгалаад, дараа нь "Засах"-аар дахин нээнэ.
  2. "📷 Зураг нэмэх"-ээр олон зураг оруулна. Зураг дарж үндсэн болгоно; ✕-ээр устгана.
Харагдах-ыг унтраавал тухайн өрөө зочны сайтад харагдахгүй.

🖼️ Сайтын зураг

Зураг таб дээр нүүр хуудасны слайдыг удирдана.

  • Нүүр (hero) слайд — эхний дэлгэцийн дэвсгэр
  • Танилцуулга слайд — "Танилцуулга" хэсэг

"📷 Зураг нэмэх"-ээр олон зураг оруулбал автоматаар солигдоно. ✕-ээр устгана. Зураггүй бол энгийн дэвсгэр харагдана.

📋 Захиалга удирдах

Захиалга таб дээр ирсэн захиалгыг харж боловсруулна. Шинэ захиалга байвал таб дээр улаан тоо гарна.

Төлөв

  • Хүлээгдэж буй сая илгээгдсэн (шийдээгүй)
  • Баталгаажсан зөвшөөрсөн → зочинд баталгаажуулах имэйл
  • Боломжгүй авах боломжгүй → зочинд мэдэгдэнэ, огноо чөлөөлөгдөнө
  • Цуцалсан баталгаажсаны дараа цуцалсан → мэдэгдэнэ, огноо чөлөөлөгдөнө

Боловсруулах

  1. Мөр бүрийн ✔ Батлах / ⊘ Боломжгүй / ✖ Цуцлах товч ашиглана.
  2. Төлөв өөрчлөхөд зочин, эзэн хоёуланд автомат имэйл илгээгдэнэ.
  3. 🗑-ээр устгана. Дээд шүүлтүүрээр төлвөөр харна.
Боломжгүй/Цуцалсан огноог чөлөөлдөг; зөвхөн Хүлээгдэж буй/Баталгаажсан огноог барина. Нэг өрөөний давхцсан огноо автоматаар хаагдана.

⚙️ Тохиргоо — үндсэн хэл

Тохиргоо таб дээр сайтын үндсэн хэл-ийг тогтооно (анхдагч: Англи). 🇲🇳/🇰🇷/🇬🇧 дарахад тэр даруй хадгална. Зочин өөрөө сонгосон хэл давамгайлна.

🔒 Нууц үг

  1. Баруун "···" цэс → Нууц үг.
  2. Одоогийн → шинэ (4+ тэмдэгт) → давтаж, хадгална.
  3. Бусад төхөөрөмж гарна, одоогийн цонх хэвээр.
Нууц үгээ найдвартай хадгал. Мартвал зөвхөн серверийн ADMIN_PASSWORD-оор сэргээнэ.

🛠️ Асуудал шийдвэрлэх / FAQ

Имэйл ирэхгүй байна

  1. Имэйл тест-ийн үр дүнг хар.
  2. Амжилттай атал харагдахгүй бол спам шалга.
  3. Амжилтгүй бол илгээгч бүртгэл/нууц үгээ шалга.

Захиалга/зураг/тохиргоо алга болдог

Серверийн байнгын хадгалалт (volume) холбогдсон байх ёстой. Дахин суулгасны дараа алга болбол оператороос volume-ийг шалгуулна.

Зочин "Алдаа гарлаа" гэж хардаг

Ихэвчлэн удаан нээлттэй байсан хуудасны асуудал. Дахин ачаалаад (Ctrl+F5) дахин оролдоно.

Үндсэн нь Англи атал би Солонгосоор харж байна

Тэр хөтөч өмнө нь Солонгос сонгосон. Үндсэн хэлийг нууц цонхоор шалга.
